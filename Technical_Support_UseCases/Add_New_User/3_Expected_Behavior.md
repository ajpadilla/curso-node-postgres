# Add New User - Expected Behavior

## ✅ Success Scenario

When input is valid:

- Status: **201 Created**
- Data is persisted successfully
- Response is returned to client
- Resource ID is generated

---

## 📋 Response Body

On success, response contains:

- `id` → UUID generated by database
- `email` → Same as provided
- `password` → ❌ Not returned (stored hashed)

---

## 📌 Business Rules

### Validation

- Invalid input → **400 Bad Request**
- Missing required fields → **400 Bad Request**

### Uniqueness

- Duplicate email → **409 Conflict**

### Security

- Password must be hashed before storing
- Plain passwords are never returned

### System Errors

- Unexpected errors → **500 Internal Server Error**

---

## ❗ Error Handling

| Scenario           | Status Code | Message Example          |
|--------------------|-------------|--------------------------|
| Validation error   | 400         | "Invalid email format"   |
| Duplicate resource | 409         | "Email already exists"   |
| Server failure     | 500         | "Internal server error"  |
